# Triton-programming language
# 🔱 Язык программирования Triton (.tn)

Высокоуровневый интерактивный язык программирования с русскоязычным синтаксисом, созданный для быстрого прототипирования, обучения алгоритмам и выполнения легковесных скриптов прямо в веб-браузере.

**Разработчик:** `Timer-Community`  
**Среда выполнения:** HTML5 / JavaScript (Транспилятор реального времени)  
**Расширение файлов:** `.tn`

---

## 🚀 О проекте

**Triton** — это интерпретируемый язык, синтаксис которого вдохновлен Python, но полностью адаптирован под русский язык. Проект поставляется вместе с готовой интерактивной веб-песочницей (Sandbox), которая включает в себя:
1. **Редактор кода** с поддержкой динамического ввода.
2. **Интерактивную документацию** на 50 встроенных функций (вставка кода по клику).
3. **Виртуальный терминал** для мгновенного вывода результатов и отладки ошибок.

Язык работает на базе технологии **транспиляции**: написанный вами код на Triton преобразуется в оптимизированный JavaScript-код стандарта ES5/ES6 прямо "на лету" и безопасно выполняется в изолированном контексте браузера.

## 🛠️ Основной синтаксис

### Объявление переменных
В Triton отсутствует строгая типизация. Переменные объявляются с помощью ключевого слова `переменная`:
```python
переменная имя = "Алексей"
переменная возраст = 25
переменная баланс = 1500.75
```

### Логические типы
Вместо привычных `true` и `false` используются русские аналоги:
```python
переменная готов = истина
переменная занят = ложь
```

### Комментарии
Любые строки, начинающиеся с символа `#`, игнорируются интерпретатором:
```python
# Это комментарий. Он не будет выполнен.
вывод("Это код")
```

## 📚 Подробный справочник встроенных функций (50 функций)

Все встроенные функции Triton разделены на 6 логических групп.

### 1. Базовые функции

| Функция | Описание | Пример использования |
| :--- | :--- | :--- |
| `вывод(значение)` | Печатает текст, число или объект в терминал. | `вывод("Привет, Мир!")` |
| `тип(объект)` | Возвращает строковое представление типа данных. | `переменная т = тип(123)` (вернет "number") |
| `пусто(объект)` | Проверяет, является ли объект пустым (`null`/`undefined`). | `если(пусто(х))` |
| `длина(объект)` | Возвращает длину строки или количество элементов массива. | `длина("Тритон")` (вернет 6) |

### 2. Работа со строками

| Функция | Описание | Пример использования |
| :--- | :--- | :--- |
| `аппер(строка)` | Переводит всю строку в ВЕРХНИЙ регистр. | `аппер("привет")` -> `"ПРИВЕТ"` |
| `ловер(строка)` | Переводит всю строку в нижний регистр. | `ловер("ТЕКСТ")` -> `"текст"` |
| `убрать_пробелы(стр)` | Удаляет пробельные символы по краям строки. | `убрать_пробелы("  х  ")` -> `"х"` |
| `замена(стр, что, чем)` | Заменяет первое вхождение подстроки на новое значение. | `замена("Кот", "К", "Р")` -> `"Рот"` |
| `содержит(стр, подстр)` | Проверяет, входит ли подстрока в основную строку. | `содержит("Тритон", "Три")` -> `истина` |
| `разбить(стр, разд)` | Разбивает строку на массив по указанному разделителю. | `разбить("а,б,в", ",")` |
| `повторить_стр(стр, N)` | Повторяет указанную строку N раз. | `повторить_стр("Да", 3)` -> `"ДаДаДа"` |
| `индекс_стр(стр, подстр)`| Возвращает индекс первого вхождения подстроки (или -1). | `индекс_стр("Код", "д")` -> `2` |
| `срез(стр, от, до)` | Вырезает часть строки с индекса `от` до `до` (не включая `до`).| `срез("Тритон", 0, 3)` -> `"Три"` |
| `начинается_с(стр, подстр)`| Проверяет, начинается ли строка с указанных символов. | `начинается_с("Тритон", "Три")` |
| `заканчивается_на(..)` | Проверяет, заканчивается ли строка на указанные символы. | `заканчивается_на("Тритон", "он")` |
| `символ_в(стр, индекс)` | Возвращает одиночный символ по его индексу. | `символ_в("Тритон", 1)` -> `"р"` |
| `код_символа(стр, инд)` | Возвращает числовой код Юникода для символа. | `код_символа("A", 0)` -> `65` |
| `из_кода_символа(код)` | Создает строку из числового кода Юникода. | `из_кода_символа(65)` -> `"A"` |

### 3. Математические вычисления

| Функция | Описание | Пример использования |
| :--- | :--- | :--- |
| `корень(число)` | Вычисляет квадратный корень. | `корень(49)` -> `7` |
| `модуль(число)` | Возвращает абсолютное значение числа. | `модуль(-5)` -> `5` |
| `округление(число)` | Округляет дробь до ближайшего целого по правилам математики.| `округление(4.6)` -> `5` |
| `округлить_вниз(число)` | Округляет дробь до ближайшего меньшего целого. | `округлить_вниз(4.9)` -> `4` |
| `округлить_вверх(число)`| Округляет дробь до ближайшего большего целого. | `округлить_вверх(4.1)` -> `5` |
| `степень(база, эксп)` | Возводит число в указанную степень. | `степень(2, 3)` -> `8` |
| `случайно(мин, макс)` | Генерирует случайное целое число в диапазоне. | `случайно(1, 10)` |
| `макс(а, б)` | Возвращает наибольшее из двух чисел. | `макс(10, 20)` -> `20` |
| `мин(а, б)` | Возвращает наименьшее из двух чисел. | `мин(10, 20)` -> `10` |
| `пи()` | Возвращает математическую константу Пи. | `пи()` -> `3.141592653589793` |
| `синус(число)` | Вычисляет синус угла (в радианах). | `синус(0)` -> `0` |
| `косинус(число)` | Вычисляет косинус угла (в радианах). | `косинус(0)` -> `1` |
| `тангенс(число)` | Вычисляет тангенс угла. | `тангенс(0)` |
| `лог(число)` | Вычисляет натуральный логарифм. | `лог(1)` -> `0` |

### 4. Динамические массивы (Списки)

| Функция | Описание | Пример использования |
| :--- | :--- | :--- |

| `массив_объединить(м, р)`| Превращает массив в строку с разделителем `р`. | `массив_объединить(м, "-")` |
| `массив_развернуть(м)` | Разворачивает порядок элементов в массиве. | `массив_развернуть(мой_массив)` |
| `массив_сортировать(м)` | Сортирует массив по возрастанию/алфавиту. | `массив_сортировать(мой_массив)` |
| `массив_индекс(м, эл)` | Возвращает индекс искомого элемента (или -1). | `массив_индекс(мой_массив, 10)` |
| `массив_вырезать(м, о, д)`| Копирует часть элементов в новый массив от `о` до `д`. | `массив_вырезать(мой_массив, 0, 2)` |
| `массив_заполнить(м, з)` | Заполняет существующий массив значением `з`. | `массив_заполнить(мой_массив, 0)` |
| `массив_включает(м, эл)` | Проверяет, есть ли элемент в массиве (`истина`/`ложь`).| `массив_включает(мой_массив, 9)` |

### 5. Конвертация и валидация типов

## 💻 Пример сложного скрипта на Triton

```python
# Демонстрация возможностей языка Triton от Timer-Community
вывод("=== ЗАПУСК СИСТЕМНОГО ТЕСТА ===")
вывод("Время запуска: " + дата_текст())

# Генерация данных
переменная пароль = "  Triton_Secure_2026  "
переменная очищенный = убрать_пробелы(пароль)

вывод("Оригинальный пароль: " + пароль)
вывод("Очищенный пароль: " + очищенный)
вывод("Длина пароля: " + в_строку(длина(очищенный)))

# Математический блок
переменная база = 2
переменная степень_числа = 10
переменная результат = степень(база, степень_числа)
вывод("2 в степени 10 равно: " + в_строку(результат))

# Работа со списками
переменная логи = массив_создать("Старт", "Авторизация")
массив_добавить(логи, "Успех")
вывод("Текущие логи сессии:")
вывод(логи)
```

## ⚙️ Архитектура ядра (Под капотом)

Язык работает на простом движке регулярных выражений, который последовательно заменяет лексемы Triton на валидный JavaScript. Пример трансформации кода:

```javascript
// Код Triton написанный пользователем:
переменная х = корень(16)
вывод(х)

// Во что его превращает транспилятор перед запуском:
let x = Math.sqrt(16);
tritonLog(x);
```

Благодаря архитектуре без внешних зависимостей, среда разработки запускается мгновенно на любых устройствах без необходимости установки Node.js, Python или компиляторов.
